# Sources and provenance

Checked 2026-10-08. These are communication and engineering references, not clinical reference ranges or diagnostic guidelines. This package contains newly authored instructions and synthetic cases; it does not bundle third-party source files, corpora, models, or fonts.

1. CDC, Everyday Words for Public Health Communication: https://www.cdc.gov/ccindex/everydaywords/about.html . Guidance on familiar words, defining terms and rewriting in context. Adapted as general communication principles, not as a Thai-specific efficacy claim.
2. CDC, Clear Communication Index: https://www.cdc.gov/ccindex/ . Public communication assessment; no claim that its scoring has been validated for this Thai chatbot.
3. AHRQ, Health Literacy Universal Precautions Toolkit, Tool 5: https://www.ahrq.gov/health-literacy/improve/precautions/tool5.html . Comprehension checking/teach-back principles, adapted cautiously for conversational use.
4. OWASP, LLM Prompt Injection Prevention Cheat Sheet: https://cheatsheetseries.owasp.org/cheatsheets/LLM_Prompt_Injection_Prevention_Cheat_Sheet.html . Consulted for separation, least privilege and layered checks; no code copied.
5. Adem Kurtipek, gencharitaci/humanize-skills: https://github.com/gencharitaci/humanize-skills . README identifies CC BY 4.0. Consulted as a writing reference only; no repository text is redistributed here. Medical file blob: 6997b7806377f70a50bac922f9fdf87b3d39f04e. Thai file blob: 260d3ed839f9df22c547d6a4309cc3e85886fc1f. These are FILE blob SHAs, not repo commit IDs. The Thai file explicitly says it is unvalidated and not native-speaker reviewed. This package does not adopt that file's speculative claims as established Thai-language rules.
6. PyThaiNLP: https://github.com/PyThaiNLP/pythainlp . Optional host utility, not included as a dependency. Check licenses for individual corpora and models separately.

No source endorses LabClear, this package, any selected LLM, or a clinical deployment.
