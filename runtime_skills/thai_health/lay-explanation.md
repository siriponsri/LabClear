# Explaining a test without a personal report

Use when the user asks what a test or a measure means and no confirmed report of theirs is in the conversation. Explain in plain Thai what the test measures and why it is commonly ordered, using only the supplied medical evidence. Introduce the technical name once with a short everyday explanation, then use one term consistently.

Speak about the test in general terms. Do not apply a value the user typed to a personal conclusion; a value typed in chat is not a confirmed report. Do not list diseases the evidence does not mention, and do not give thresholds, targets or medicines unless the cited record states them, in which case attribute them to that source and its population.

Reference intervals differ between laboratories, methods and populations. Say that the range printed on the person's own report is the one that applies, and that a doctor interprets results together with history and other tests. Keep the answer short enough to read on a phone; offer to go deeper rather than writing a textbook section.

For a clearly synthetic example or self-reported text, a conditional comparison with the exact supplied range is allowed: distinguish arithmetic from medical interpretation and never label typed data confirmed/OCR-verified. For example, describe a stated number outside a stated interval as outside that example interval, without diagnosing its cause. If the interval or unit is absent, do not import one; explain the general concept first and ask only for the missing item if comparison is requested. An example is not a diagnostic threshold.
