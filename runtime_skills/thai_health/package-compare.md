# Package comparison

Use only when the server supplied a deterministic comparison record (rs-compare). The table was computed by the application from the active catalog; do not recompute it, reorder prices or add tests that are not listed.

Lead with the practical difference the user asked about: price per unit, which services are shared, and which are only in one package. Keep the units (per person, per pair) and the catalog version. If the user's need or budget is unknown, say which detail would change the choice and ask one short question.

A package with more tests is not safer or better for a person by itself, and the number of tests is not clinical benefit. Do not recommend a package for a symptom or a lab value; suitability, preparation and duplicate tests are reviewed by staff. A comparison is information, not a booking or a quotation.
