## คำเปลี่ยนช่วง

- หลังหน้า 4: “เราเห็นจุดที่ผู้ใช้ต้องตรวจและยืนยันแล้ว ต่อไปจะดูว่าระบบแยกสิทธิ์ แหล่งข้อมูล และการส่งต่ออย่างไร”
- ก่อนหน้า 10: “ผลทดสอบในเครื่องช่วยยืนยัน workflow บางส่วน แต่ยังไม่ตอบเรื่องคุณภาพทางคลินิกหรือความพร้อมใช้งานจริง”
- ปิดท้าย: “สิ่งที่นำเสนอเป็นต้นแบบและหลักฐานทดสอบในเครื่อง ขั้นต่อไปต้องผ่านการตรวจคุณภาพ ความเป็นส่วนตัว การปฏิบัติการ และเศรษฐศาสตร์ก่อนสื่อสารว่าเป็นบริการจริง”

## คำตอบที่ยึดหลักฐาน

| คำถาม | คำตอบ |
|---|---|
| LabClear เป็นคลินิกหรือเครื่องมือวินิจฉัยหรือไม่ | ไม่ใช่ เป็นเพียงต้นแบบ และยังไม่มีผู้เชี่ยวชาญรับรองความถูกต้องทางคลินิก |
| ผล 37 จาก 37 หมายถึงอะไร | การทดสอบงานผ่านเว็บในเครื่องด้วยข้อมูลสร้างขึ้นและตัวแทนระบบภาษา/อ่านข้อความจากภาพ ไม่ใช่การทดสอบกับผู้ใช้จริงหรือการวัดคุณภาพคำตอบ |
| ระบบจองและชำระเงินจริงหรือไม่ | ไม่ใช่ รายการแพ็กเกจ การจอง และการชำระเป็นตัวอย่างจำลอง ไม่มีการโอนเงิน |
| ระบบอ่านข้อความจากภาพแม่นแค่ไหน | ยังไม่มีการวัดกับผู้ให้บริการจริง รอบนี้ตรวจเพียงว่าขั้นตอนทำงานกับตัวแทนได้ |
| การค้นเอกสารทำให้คำตอบถูกต้องหรือไม่ | ไม่รับรองความจริง การแสดงแหล่งอ้างอิงช่วยให้ตรวจที่มาได้เท่านั้น |
| ราคาปัจจุบันเป็นราคาขายหรือไม่ | ไม่ใช่ เป็นราคาในตัวอย่าง ไม่มีข้อมูลต้นทุน กำไรต่อรายการ หรือความเต็มใจจ่ายเพียงพอให้กำหนดราคาจริง |
| พร้อมเปิดใช้งานจริงหรือยัง | ยังสรุปไม่ได้ ต้องตรวจความเป็นส่วนตัว การเก็บและกู้คืนข้อมูล ความเสถียร ความถูกต้องทางคลินิก คุณภาพบริการ และความคุ้มค่าทางธุรกิจ |

## เมื่อสาธิตไม่ได้

1. ใช้ขั้นตอนตัวอย่างในเครื่องและข้อมูลที่สร้างขึ้นเท่านั้น
2. ปิดแผงตั้งค่า รหัสลับ รายงานดิบ และข้อมูลระบุตัวบุคคลก่อนแชร์หน้าจอ
3. หากบริการที่ต้องใช้ไม่พร้อม ให้ข้ามการสาธิต เวลาสำรองมี 30 วินาที
4. หากเปิดภาพข้อมูลไม่ได้ ให้อธิบายจากแผนภาพขั้นตอนแบบสถิต โดยไม่เรียกข้อมูลหรือบริการภายนอก
5. HTML เป็นไฟล์นำเสนอหลัก ส่วน PDF ใช้อ่านหรือพิมพ์แบบสถิต ห้ามใช้ไฟล์ส่งออกหรือภาพเก่าแทนผลรอบปัจจุบัน
