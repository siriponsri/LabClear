ไม่มี build step ไม่มี CDN ไม่มี API call ทุกไฟล์อยู่ในโฟลเดอร์ (ฟอนต์ IBM Plex Sans Thai + Geist จาก `static/fonts/`) `vercel.json` ตั้ง CSP ให้โหลดได้เฉพาะไฟล์ของตัวเอง และใส่ `noindex`

## Deploy บน Vercel (2 ลิงก์)

1. Push โฟลเดอร์นี้ขึ้น GitHub (`siriponsri/LabClear`)
2. Vercel → **Add New Project** → เลือก repo → **Root Directory** = `presentation/20261025/slides` · Framework Preset = **Other** · ไม่ต้องตั้ง Build Command / Output Directory → Deploy
3. ทำซ้ำอีกโปรเจกต์ ตั้ง Root Directory = `presentation/20261025/script`
4. (แนะนำ) Settings → Deployment Protection ถ้าไม่อยากให้คนนอกเปิดบทพูดหรือภาพ PDF ศิริราช

หลังจากนั้น ทุกครั้งที่ push ขึ้น branch หลัก Vercel จะ deploy ใหม่เอง

## นำเสนอบน Microsoft Teams

- ศิริพลเปิดลิงก์สไลด์ใน Chrome/Edge → กด **F** เต็มจอ → Teams แชร์แบบ **Screen** (ทั้งจอ)
- พี่วัชรินทร์เปิดลิงก์บทพูดบนมือถือ กด **A** เพื่อเน้นบทตัวเอง และกด **เริ่ม** ที่นาฬิกาตอนพูดคำแรก
- ศิริพลกดทุกคลิก (35 คลิก) ตามป้าย `[คลิก n]` ในบทพูด

| คีย์ | ทำอะไร |
| --- | --- |
| → ↓ Space PgDn | คลิกถัดไป (ใช้ presenter clicker ได้) |
| ← ↑ PgUp | ย้อนกลับ |
| 1–8 | ไปต้น section นั้น |
| Home / End | แผนที่ภาพรวม / Next Steps |
| O | ซูมออกดูภาพรวมชั่วคราว (กดอีกครั้งเพื่อกลับ) |
| F | เต็มจอ (ถ้าเบราว์เซอร์ไม่ยอม ใช้ F11) |
| L | เลเซอร์พอยน์เตอร์ (จุดแดงตามเมาส์) |
| Q | หน้าสำรอง Q&A · Esc เพื่อกลับ |
| H หรือ ? | คีย์ลัด |

ลิงก์ตรงไปเฟรมได้ เช่น `…/#/k3` หรือ `…/#/e1.2` (เฟรม e1 คลิกที่ 2)

## แก้บทพูดโดยไม่เขียนโค้ด

แก้ `script/SPEAKER_SCRIPT_TH.md` บนหน้าเว็บ GitHub (ปุ่มดินสอ) แล้ว Commit · หน้า script จะโหลดเวอร์ชันใหม่หลัง Vercel deploy เสร็จ รูปแบบบรรทัดอธิบายไว้ในคอมเมนต์ต้นไฟล์ (`A:` / `B:` บทพูด, `[คลิก n]` จุดกด, `> TRANSITION:` ประโยคเชื่อม, `**คำ**` คำเน้น)

ถ้าแก้ลำดับหรือจำนวนคลิกในบท ต้องให้ตรงกับสไลด์: แต่ละ "ถัดไป" จะเปิดขั้นถัดไปของเฟรม หรือย้ายไปเฟรมถัดไป รวม 35 ครั้ง

## เปิดดูในเครื่อง

```bash
python -m http.server 8811 --directory presentation/20261025/slides
```

เปิด `http://localhost:8811` · ถ้าเปิด `index.html` ตรง ๆ แบบ file:// สไลด์ก็ทำงานได้ แต่หน้าบทพูดต้องใช้ server เพราะโหลดไฟล์ .md

- `?still` แสดงทุกการเคลื่อนไหวแบบทันที (สำหรับเครื่องช้าหรือถ่ายภาพ)
- จอแคบกว่า 760px หรือแนวตั้ง จะเป็นโหมดอ่านที่ไหลลง ไม่ย่อทั้งหน้า
- ปิด JavaScript ก็ยังอ่านทุกเฟรมได้ครบแบบเลื่อนลง
- พิมพ์ / Save as PDF ได้ 1 เฟรมต่อหน้า แนวนอน (ทุกขั้นเปิดครบ ไม่มีปุ่มควบคุม) · หน้าแรกเป็นการ์ดชื่อโครงงานสำหรับฉบับพิมพ์
