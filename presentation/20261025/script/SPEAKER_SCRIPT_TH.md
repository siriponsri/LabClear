A: แถบด้านล่างสำคัญครับ ตอนเทียบค่าบนรายงาน ระบบใช้**ช่วงอ้างอิงที่พิมพ์อยู่บนรายงานที่ผู้ใช้ยืนยันแล้ว** ไม่ได้เอาค่าจากคลังไปตัดสิน

B: ระบบนี้**ไม่ได้แปลงเป็น embedding vector** และ**ไม่มี vector database** ครับ เราเลือกค้นด้วยคำเพราะตรวจย้อนได้ว่าทำไมได้ผลนี้

> ระวัง: ถ้าอาจารย์ชี้ตัวแปร `vectors` ใน `_index()` ตอบว่า "ตัวนี้คือความถี่คำจาก Counter ครับ ไม่ใช่ embedding จากโมเดล"

### สไลด์ 32 · Safety and Data Boundaries

::cue ใช้ตอบ: "ข้อมูลผู้ใช้ออกนอกเครื่องไหม" · "กัน prompt injection ยังไง"
