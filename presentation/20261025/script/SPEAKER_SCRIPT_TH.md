A: แถบด้านล่างสำคัญครับ ตอนเทียบค่าบนรายงาน ระบบใช้**ช่วงอ้างอิงที่พิมพ์อยู่บนรายงานที่ผู้ใช้ยืนยันแล้ว** ไม่ได้เอาค่าจากคลังไปตัดสิน

::cue บนจอ: ขั้นอ่านภาพ → ตรวจ → ยืนยัน · กรอบเลื่อนจากแถบเตือนไปที่ปุ่ม

B: ถ้าข้อมูลไม่ผ่านการตรวจ ระบบจะ**แจ้งเหตุแทนการแสดงคำอธิบาย** รอบที่บันทึกนี้ก็เป็นแบบนั้นครับ

> TRANSITION: "ฟังก์ชันเหล่านี้อยู่ในเว็บเซอร์วิสหลักตัวเดียว ต่อไปเป็นโครงสร้างว่าแต่ละส่วนรับผิดชอบอะไรครับ"

### สไลด์ 22 · How Retrieval Works (RAG)

::cue ใช้ตอบ: "การทำ RAG ทำอย่างไร"

B: RAG ของเราทำ 5 ขั้นครับ หนึ่ง ความรู้เก็บเป็น **JSON** ที่ `knowledge/evidence/catalog.json` สอง Python โหลดและ**ตรวจ hash** ใน `corpus()` สาม **แยกคำ** คำอังกฤษตัดเป็นคำ ภาษาไทยใช้**คู่อักษร** แล้วนับความถี่ สี่ จัดอันดับด้วย **BM25** ใน `lexical()` ห้า ผลที่ค้นได้ถูกใส่เป็น **EVIDENCE** ใน prompt ให้โมเดลเขียนคำตอบครับ
